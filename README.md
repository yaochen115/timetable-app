# 林木课表

一个用于管理学期、每周课程和作息时间的课表应用，当前提供 Android 版本。

## 项目入口

- [应用源码与构建说明](应用/README.md)
- [需求说明](需求确认.md)
- [交接文档](交接文档.md)
- [安卓安装与验收](安卓安装与验收.md)

`应用/web/` 保存界面和课表逻辑，`应用/android/` 保存 Android WebView 容器；`设计稿/` 和 `验收/` 保存设计及校验资料。

## 运行与构建

在本目录运行 `node ./应用/build-android.mjs`。需要本机配置 Android SDK 和 JDK，具体环境变量和检查方法见应用源码说明。

当前版本为 Android 1.0.1。已完成构建及包内资源检查，仍需真机覆盖安装验证，详见验收文档。

## 本地文件

签名密钥、浏览器临时数据、构建缓存及 APK 不纳入 Git。更新已安装应用需要保留原有签名密钥，请在本地妥善备份。安装包位于本地 `安装包/`。
